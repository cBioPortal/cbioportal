# Migration Guide

This page describes changes deployers need to make as they deploy newer versions of the portal.

## v6.4 -> v7.0

- v7 replaces MySQL with ClickHouse as the only supported database. See [v6 to v7 Migration](Migration-v6-to-v7.md).

Migration notes for v6 and earlier have been removed, since those releases are no longer supported. If you are upgrading from a version older than v6.4, see the [release notes](https://github.com/cBioPortal/cbioportal/releases) for the versions in between, then follow the v6 to v7 migration guide.
